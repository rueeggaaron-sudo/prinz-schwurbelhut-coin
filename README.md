# Prinz Schwurbelhut Coin (PSHC)

BEP-20 Token auf BNB Smart Chain.

## Core Specs
- Name: Prinz Schwurbelhut Coin
- Symbol: PSHC
- Decimals: 0 (nur ganze Hüte)
- Total Supply: 21,000,000,000 (fix beim Deploy)

## Tokenomics
- 4.2% Transfer Tax
  - 2.1% Burn
  - 2.1% Treasury (Hutkasse)

## Admin Controls
- Treasury Wallet änderbar
- Tax anpassbar (0–10%)
- Burn/Treasury Split anpassbar (Summe = Tax)
- MaxTx (default 1%)
- MaxWallet (default 2%)
- Limits deaktivierbar

## Ziel
Sauberer, deploybarer BEP-20 Contract
für BSC Testnet & Mainnet.
